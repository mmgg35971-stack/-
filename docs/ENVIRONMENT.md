# ما أمكن وما لم يمكن في بيئة البناء

العمل تم في حاوية سحابية بدون مفاتيحك وبدون Android SDK.

| البند | الحالة |
|---|---|
| ترحيلات Postgres واختبارات القواعد والتزامن | ✅ شُغّلت فعلياً على PostgreSQL محلي ونجحت كلها |
| Edge Functions: فحص الأنواع والـ lint والاختبارات | ✅ شُغّلت فعلياً بـ Deno 2 ونجحت |
| بناء تطبيق Android | ❌ تحميل Android SDK محجوب في الحاوية، لذا البناء والاختبارات تتم في GitHub Actions (`android.yml`) |
| استدعاء Claude وGoogle Vision فعلياً | ❌ لا توجد مفاتيح. الكود مكتوب على الواجهات الرسمية ومغطى باختبارات وحدة للتحليل والتحقق. |
| مشروع Supabase حقيقي وGoogle OAuth | ❌ يحتاج حساباتك ([SETUP.md](setup/SETUP.md)) |
| Google Play Billing والتوقيع | ❌ يحتاج حساب مطوّر Play وkeystore خاصاً بك |
